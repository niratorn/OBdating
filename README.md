# OBdating: คำนวณอายุครรภ์และ EDC

เปิดใช้งาน: https://niratorn.github.io/OBdating/

เว็บช่วยคำนวณอายุครรภ์ (GA) และกำหนดคลอด (EDC) จาก LMP และอัลตราซาวด์ สำหรับงานฝากครรภ์และงานวิจัยทางสูติกรรม วันที่ตรวจเปลี่ยนตามวันจริงเอง จึงไม่ต้องปิดแล้วเปิดหน้าใหม่ เมื่อมีทั้ง LMP และ U/S ระบบเทียบผลต่างตามเกณฑ์ redating แล้วเขียนการรายงาน/บันทึก GA ให้ เช่น `GA 17+3 Wk by date = U/S at GA 16+3 wk`

แท็บงานวิจัยมี 2 โหมด โหมดตารางทำทีละคน ใส่ EDC ที่ถูกต้อง วางวันที่รับบริการจาก Google Sheet แล้วคัดลอก GA เป็นสัปดาห์และวันกลับไปวาง ส่วนโหมดไฟล์คำนวณจากไฟล์ Excel หรือ CSV หลายราย ทั้งสองโหมดคำนวณในเบราว์เซอร์ ข้อมูลไม่ถูกส่งออกจากเครื่อง

เครื่องมือช่วยคำนวณ ไม่ใช่เครื่องมือแพทย์ ผลลัพธ์ใช้ประกอบการตัดสินใจของแพทย์

## แก้ไขและอัปเดต

แก้ไฟล์ใน `src/` แล้วดับเบิลคลิก `deploy.bat` ไฟล์นี้สร้าง `index.html` ใหม่ รันการทดสอบ แล้ว push ขึ้น GitHub ผลการทำงานอยู่ใน `deploy-log.txt`

SheetJS Community Edition 0.18.5 อยู่ใน `vendor/` ภายใต้ Apache License 2.0

ฟอนต์ IBM Plex Sans Thai และ Trirong อยู่ใน `fonts/` ภายใต้ SIL Open Font License 1.1 หน้าเว็บจึงไม่ติดต่อเว็บภายนอก
